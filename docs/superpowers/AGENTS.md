- `specs/` holds design requirements and acceptance criteria.
- `plans/` holds dated implementation steps, scoped ownership, and verification records.
- [trials](../trials/AGENTS.md) holds observed experiments; [docs](../AGENTS.md) holds user-facing instructions.

Reuse the existing spec or plan when continuing the same work.
Keep proposed work, approved scope, and completed steps distinguishable.
Mark steps complete only when their stated verification has run; record any remaining limits beside the result.
Update user guides and architecture references when implementation changes them; a plan is not their replacement.
