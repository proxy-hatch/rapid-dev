# Provider setup

These terms distinguish the evidence used when a project selects coding providers and models.

## Language

**Provider observation:** A dated result from inspecting a coding provider or explicitly checking a selected model. Discovery alone does not establish model authentication.

**Model verification:** Evidence that an explicitly selected model satisfied its provider's verification procedure. An agy verification requires a completed inference response for that exact model.

**Provider evidence:** The latest provider observation together with retained model verifications. Refreshing discovery does not renew earlier model verifications.

**Model readiness:** Eligibility to select a model using a recent catalog and the authentication evidence required by its provider. It does not qualify an execution environment or authorize delivery.
